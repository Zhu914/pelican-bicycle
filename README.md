# 鹈鹕骑士 · Pelican Rider

一只戴红围巾的鹈鹕，骑着一辆藤编车篮里装着鱼的自行车，沿海岸公路前行。

**在线访问：<https://zhu914.github.io/pelican-bicycle/>**

整个页面是一个 **750 KB 的单文件 HTML**：没有外部依赖，不加载任何图片、模型或音频文件——鹈鹕、自行车、天空、海面、纹理和声音全部在运行时程序化生成。需要支持 WebGL2 的浏览器。

## 场景里有什么

- **鹈鹕**：放样出来的身体、长颈、带钩长喙和下垂的喉囊；翅膀搭在车把上，末端是黑色飞羽；红围巾用 Verlet 物理模拟，随车速飘动。喉囊会随路面颠动，它会随机眨眼、用眼睛跟着镜头看。
- **自行车**：车架、32 辐条车轮、五孔链轮、飞轮，以及沿着真实包络线运动的实例化链条；挡泥板、藤编车篮（里面插着三条鱼）、水壶、车铃、车灯和一块 `PELI·1` 车牌。
- **踩踏**：双腿用双骨 IK 实时解算，蹼足始终踩在踏板上；车轮转速与地面速度一致，踏频由齿比决定；减速时腿会停下来滑行。
- **海岸**：着色器绘制的天空（太阳、月亮、星星、云）与海面（菲涅尔反射、浪花、粼光）；滚动经过的公路、路灯、棕榈、长椅、遮阳伞、帆船、海鸟、灯塔，偶尔有鱼跃出海面。
- **昼夜**：拖动"时刻"即可从日出走到午夜。路灯和车灯在夜里亮起，灯塔开始扫射，草丛里出现萤火虫。环境光贴图直接从当前天空实时采集。

## 操作

| 操作 | 作用 |
| --- | --- |
| 拖拽 / 滚轮 / 双指 | 旋转、缩放视角 |
| `↑` `↓`（或 `W` `S`） | 加速、减速 |
| `Space` | 冲刺并鸣叫 |
| `B` | 按车铃 |
| `N` | 昼夜切换 |
| `C` | 下一个机位 |
| `P` | 暂停 / 继续 |
| `H` | 隐藏 / 显示界面 |
| `M` | 声音开关 |
| `L` | 中 / 英切换 |
| `R` | 复位 |

点击场景里的**鹈鹕**、**车铃**或**鱼**会有反应。面板里还可以切换涂装、线框、慢动作、电影机位，以及保存截图、复制分享链接。

## 分享链接

场景状态会写进地址栏，也可以手动拼接：

```
?speed=30&time=0.455&cam=side&color=coral&lang=zh
```

- `speed`：速度，km/h，0–45
- `time`：时刻，0 日出 · 0.25 正午 · 0.5 日落 · 0.75 午夜
- `cam`：`hero` `side` `front` `chase` `face` `detail` `top` `wide`
- `color`：`teal` `coral` `cream` `navy` `rose` `gold`
- `lang`：`zh` / `en`
- `autotime=1` 自动昼夜 · `rotate=0` 关闭自动环绕 · `cine=1` 电影机位 · `ui=0` 隐藏界面

## 技术说明

- **Three.js r187**（内嵌于页面，MIT 许可），WebGL2 渲染。
- **几何**：自写的放样（loft）工具沿路径蒙皮一系列椭圆截面，鹈鹕、羽毛、车座、挡泥板、棕榈叶都由它生成；静态零件合并成尽量少的绘制调用，草、花、链条、粒子使用实例化。
- **着色**：天空与海面是自定义 GLSL；海面噪声沿海岸线周期化，所以无限滚动不接缝。羽毛的凹凸在片元着色器里用屏幕空间导数求得，不需要 UV。
- **光照**：一盏投影的方向光白天是太阳、夜里是月亮；环境光贴图用立方相机从天空着色器采集，再经 PMREM 预滤波。
- **后期**：MSAA → 泛光 → ACES 色调映射 → 调色（冲刺时的径向模糊、色散、暗角、颗粒）。泛光入口会拦截非有限值，避免单个坏像素扩散成整屏变黑。
- **音频**：Web Audio 合成的风声、胎噪、链条、飞轮棘轮、车铃、鸣叫、海浪、蟋蟀与海鸟。
- **性能**：三档画质，帧率持续偏低时自动降档；竖屏会自动拉远相机以保持取景。

## 本地构建

```bash
npm install
npm run build      # 生成 dist/index.html（即仓库根目录的 index.html）
npm run dev        # 本地预览 + 监听改动：http://127.0.0.1:8787/
```

源码在 `src/`：`bicycle.js` 自行车、`pelican.js` 鹈鹕、`environment.js` 世界与光照、`particles.js` 粒子、`postfx.js` 后期、`audio.js` 声音、`main.js` 主循环与交互，`core/` 是几何、纹理和数学工具。

加上 `?debug=1` 可以在控制台查看构建信息，并通过 `window.__pelican` 访问场景对象。
